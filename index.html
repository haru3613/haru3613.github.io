Haru Video Studio

Haru Video Studio 是由管理者在自己的電腦或自行部署的私有雲端上使用的影片製作工具。Agent 可透過需要憑證的 MCP 入口建立專案、使用 Google Drive 素材及執行影片渲染。影片、聲音、封面與文字的公開發布，仍需管理者另行授權。

Haru Video Studio is a personal video production tool operated on the owner's computer or privately deployed cloud service. Authenticated agents can use its MCP interface to create projects, work with Google Drive assets, and render videos. Public publication of videos, audio, covers, and text requires separate owner authorization.

Google Drive 與 YouTube / Google Drive and YouTube

Google Drive 權限只用於此應用建立或管理者選取的檔案。YouTube 是另外授權的可選功能；目前雲端服務的 YouTube 發布仍停用。本工具目前僅供管理者使用，不提供一般觀眾登入。

Google Drive access is limited to files created by this app or selected by the owner. YouTube is an optional, separately authorized capability; YouTube publishing remains disabled in the current cloud service. This tool is for its owner, not a public viewer sign-in service.
